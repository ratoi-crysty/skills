# skills

Personal Claude Code skills.

## Install

```
/plugin marketplace add ratoi-crysty/skills
/plugin install skills@ratoi-crysty
```

## Skills

- **react-components** — Conventions for authoring React components (memoization, widgets pattern, UI library usage).
- **angular-components** — Conventions for authoring Angular components (OnPush change detection, signals-first state, widgets pattern).
